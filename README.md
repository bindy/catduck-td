# 猫鸭塔防 · 守卫小鱼干

一只猫、一只鸭，守住 20 条小鱼干。

老鼠们沿着小路来偷鱼，点空地造猫塔拦住它们。4 种猫塔（橘猫毛线球、狸花猫扑击、白猫冰爪、黑猫狙击），各 3 级；4 种老鼠（田鼠、疾行鼠、铁甲鼠，每 5 波一只鼠王），无尽波次。

鸭子是指挥官：开「自动指挥」它会帮你造塔升级；「鸭子冲锋」让它沿着小路撞飞老鼠（25 秒冷却一次）。

在线试玩：https://bindy.github.io/catduck-td/

## 技术

- three.js r170 3D 渲染（官方模块源码打包成经典脚本，转译到 ES2017）
- 纯前端、无后端、无联网，离线可玩
- 同一份代码也是小红书小工具的提交包（index.html + style.css + three.js + game3d.js）

## 玩法

- 点一块空地，选一只猫塔造上去；点已有塔可以升级或出售（返还 70%）
- 每波守住奖励 25 + 3×波次 鱼干；老鼠逃走会偷鱼，鱼被偷光游戏结束
- 最高波次会记在本地
